# QuotePilot iOS wrapper

A lightweight WKWebView container for the public progressive web app at https://marksheininwork-netizen.github.io/quotepilot/. The native wrapper adds iOS navigation gestures, a loading indicator, and a retry prompt for temporary network failures.

Open `QuotePilot.xcworkspace` in Xcode and choose the `QuotePilot` scheme. The bundle identifier is `com.mariasheinin.quotepilot`. Configure the Apple Developer Team in Xcode signing settings before archiving.

This wrapper requires internet access to load the hosted app and is not a replacement for an App Store review of product functionality.
